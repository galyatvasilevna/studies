## Полный код решения

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <map>
using namespace std;

// ============================================================
// ЧАСТЬ 1: АЛГОРИТМ КМП (Кнута-Морриса-Пратта)
// ============================================================

// Вычисление префикс-функции
vector<int> computePrefix(const string& p) {
    vector<int> pi(p.length(), 0);
    for (int i = 1; i < p.length(); i++) {
        int j = pi[i - 1];
        while (j > 0 && p[i] != p[j]) j = pi[j - 1];
        if (p[i] == p[j]) j++;
        pi[i] = j;
    }
    return pi;
}

// Поиск всех вхождений
vector<int> kmpSearch(const string& t, const string& p) {
    vector<int> res;
    if (p.empty()) return res;
    vector<int> pi = computePrefix(p);
    int j = 0;
    
    for (int i = 0; i < t.length(); i++) {
        while (j > 0 && t[i] != p[j]) j = pi[j - 1];
        if (t[i] == p[j]) j++;
        if (j == p.length()) {
            res.push_back(i - p.length() + 1);
            j = pi[j - 1]; // Откат для поиска следующих вхождений
        }
    }
    return res;
}

// ВАРИАНТ 11: Замена всех вхождений
string replaceAll(string t, const string& p, const string& rep) {
    vector<int> pos = kmpSearch(t, p);
    if (pos.empty()) return t;
    
    string result = "";
    int last = 0;
    
    for (int idx : pos) {
        result += t.substr(last, idx - last) + rep; // Копируем текст до вхождения + замена
        last = idx + p.length(); // Сдвигаем указатель за пределы найденного слова
    }
    result += t.substr(last); // Добавляем остаток строки
    return result;
}

// ============================================================
// ЧАСТЬ 2: STL (Подсчёт частоты символов через std::map)
// ============================================================
void printCharFrequency(const string& text) {
    map<char, int> freq;
    for (char c : text) freq[c]++; // Автоматическая сортировка по ключу и подсчёт
    
    cout << "Char frequency:\n";
    for (const auto& pair : freq) {
        cout << " '" << pair.first << "': " << pair.second << "\n";
    }
}

int main() {
    string text = "ababaababcabab";
    string pattern = "abab";
    string replacement = "X";

    cout << "--- 1. KMP Algorithm ---\n";
    cout << "Original text: " << text << "\n";
    
    vector<int> positions = kmpSearch(text, pattern);
    cout << "Positions: ";
    for (int p : positions) cout << p << " ";
    cout << "\n";

    cout << "\n--- 2. Replace All (Variant 11) ---\n";
    string newText = replaceAll(text, pattern, replacement);
    cout << "Replaced text: " << newText << "\n\n";

    cout << "--- 3. STL (Map) ---\n";
    printCharFrequency(newText);

    return 0;
}
```

## Анализ сложности

| Алгоритм / Операция | Временная сложность | Пространственная сложность |
| :--- | :--- | :--- |
| **Вычисление префикс-функции** | O(M), где M — длина образца | O(M) |
| **Поиск КМП** | O(N + M), где N — длина текста | O(M) |
| **Замена (на основе КМП)** | O(N + M + K), где K — длина результата | O(N) для новой строки |
| **`std::map` (вставка/поиск)** | O(log K), где K — количество уникальных ключей | O(K) |

## Ответы на контрольные вопросы

**1. Что такое алгоритм Кнута-Морриса-Пратта (КМП)?**  
Эффективный алгоритм поиска подстроки в строке, который использует префикс-функцию, чтобы не возвращаться назад по тексту при несовпадении.

**2. В чём отличие КМП от наивного поиска?**  
Наивный поиск при несовпадении сдвигает образец на 1 символ и начинает сравнение заново (O(N*M)). КМП сдвигает образец по префикс-функции, не просматривая текст повторно (O(N+M)).

**3. Что такое префикс-функция?**  
Для каждой позиции строки это длина наибольшего собственного суффикса, который одновременно является префиксом всей строки.

**4. Как вычисляется префикс-функция?**  
Итеративно: если символы совпадают, увеличиваем счетчик; если нет — откатываемся к предыдущему значению префикс-функции `pi[j-1]`.

**5. Как работает функция `replaceAll` на основе КМП?**  
Сначала находятся все начальные индексы вхождений. Затем строка собирается заново: копируется часть до вхождения, добавляется замена, и процесс повторяется.

**6. Что такое STL?**  
Standard Template Library (Стандартная библиотека шаблонов) — набор шаблонных классов и функций в C++ (контейнеры, итераторы, алгоритмы).

**7. Что такое `std::map`?**  
Ассоциативный контейнер, хранящий пары «ключ-значение». Элементы автоматически отсортированы по ключу.

**8. Какова сложность операций в `std::map`?**  
Вставка, поиск и удаление занимают O(log N), так как внутри используется сбалансированное дерево (красно-черное).

**9. Чем `std::map` отличается от `std::unordered_map`?**  
`map` сортирует элементы по ключу (доступ O(log N)), а `unordered_map` использует хеш-таблицу, не сортирует, но в среднем работает быстрее (O(1)).

**10. Почему в `printCharFrequency` элементы выводятся в алфавитном порядке?**  
Потому что `std::map` автоматически упорядочивает элементы по возрастанию ключа.
